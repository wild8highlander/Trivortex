# `V1_inclined_registers` — 600 dpi

The spatial registers at 600 dpi: the inclination ladder, the
arc registers, the mutual-inclination matrix, the 3D J2000 sky
and the z-ladder (stage V1).

Regenerate with `make figures600` (protocol-bound; every plotted
register is read from `results/protocols/`).
