## Результат

`NGon.lean` — самодостаточный модуль «правильный `N`-угольник одинаковых точечных
вихрей» (классика Арефа 1979 в форме вынужденного вращения Кирхгофа). Главный
результат — **главная теорема `nGon_field_eq`**:

```lean
theorem nGon_field_eq {R : ℝ} {N : ℕ} (g : ℝ) (hR : R ≠ 0) (k : Fin N) :
    field g N (nGon R N) k
      = ((nGonOmega g R N : ℝ) : ℂ) * Complex.I * nGon R N k
```

— поле Кирхгофа в вершине `k` есть жёсткое вращение с **вынужденной** частотой
`ω = Γ(N−1)/(4πR²)`, и **`nGon_omega_forced`**: ЛЮБАЯ частота `ν`, при которой
многоугольник — стационарное вращающееся решение, обязана равняться `nGonOmega g R N`.
Ядро доказательства — тождество корней единства

```lean
theorem sum_ker_unity {N : ℕ} (hN : 0 < N) :
    ∑ m in Finset.univ.erase (⟨0, hN⟩ : Fin N), ker (1 - unity N (m : ℕ))
      = (((N - 1 : ℕ) : ℂ) / 2)
```

полученное из **парной тождественности** `ker_pair`: `ker(1−u_m) + ker(1−u_{N−m}) = 1`.
Мост `nGon_omega_three` воспроизводит частоту равностороннего треугольника корневого
модуля Trivortex в форме длины стороны: `ω_3 = 3Γ/(2πa²)`.

## Числовая лаборатория (независимый мост, теперь коммитится)

Каждая из 27 теорем проверена на точную формулу в float64 на сетках
`N ∈ [3,64]`, `R ∈ {0.5,1,2,3.7}`, `Γ ∈ {1,−1.5,2.3}` — худшая невязка **8.0e-14**
при допуске 1e-9. Лаборатория теперь воспроизводима кем угодно: в пакете
коммитится её скрипт `tools/numeric_lab.py` (покрытие привязано к печати:
объединение имён теорем обязано совпасть с `seal/manifest.json`); принятая запись
`data/ngon_numeric_check.json` остаётся ракетом и переписывается только явно
(`--update`). Повторный прогон в песочнице подтвердил записи: четыре группы
воспроизведены бит-в-бит, остальные — в допуске, худшая невязка совпадает (8.001e-14).
Подробности и таблица невязок: [VERIFICATION_NGON.md](VERIFICATION_NGON.md).
