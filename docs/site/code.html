The report engine

Section 12 is unusual for a research script: it renders the same result object into seven formats, including RTF-based DOCX and PDF writers with no external dependencies beyond the standard library. The repository discipline is that every number in a report must be traceable to a parameter snapshot — the report header carries the title, the version and the configuration used, and the independent ladder (Verification) re-checks the core claims outside the document's own code path.

Interaction with the verification ladder. The core document and verification/trivortex/python/verify.py are deliberately independent: different code, same objects. If a refactor ever makes the document and the ladder disagree, the pytest suite (verification/tests/) will catch it at the reference values before either side drifts.
