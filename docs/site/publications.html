The Reading Room

Every research artifact of the program exists as a typeset, language-separated document: Russian and English are separate files, and each exists in two renditions — a vector PDF (navy-gold cover, MathML equations, embedded 300-dpi figures, stamped page numbers) and an editable DOCX (native Word equations, document properties, page-number fields). The library is generated from the same markdown sources that live next to the code and rebuilds with one command: make pdf-library.

28

vector PDFs in publications/pdf — twelve study monographs × RU/EN, the core monograph × RU/EN and the research compendium × RU/EN.

28

editable DOCX in publications/docx — the same documents for word processors.

14

editable HTML sources of the study documents (1:1 with the PDF library).
