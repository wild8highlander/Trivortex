## 5. What was deliberately NOT changed

- **The license.** `LICENSE.md`, `LICENSE.ru.md`, `LICENSE.zh.md`,
  `NOTICE.md`, `REUSE.toml`, `CITATION.cff`, `.zenodo.json` are
  untouched — the personal proprietary license stays exactly as it is.
- **Every committed numeric protocol.** All numbers quoted in the new
  READMEs were read from the committed JSONs (`cycloring`,
  `polyvortex`, TRX); nothing was recomputed, retuned or rounded
  beyond the recorded precision. Test counts were verified by running
  the suites (37 + 26 + 63).
- **The science code.** The only code change is the bilingual figure
  factory in `cycloring` (label table + output routing); all physics,
  the ladders and the runners are untouched.
- **MANIFEST.json.** It is the SHA-256 provenance snapshot of the
  v1.0.0 release tied to the Zenodo DOI; it should be regenerated by
  the release process at the next version bump, not by a docs pass.
