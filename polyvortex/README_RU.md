# POLYVORTEX — стенд обобщения на N вихрей

*Самодостаточный мини-репозиторий внутри фреймворка TRIVORTEX: переход от
теоремы 3.1 для трёх вихрей к произвольному числу $N$ одинаковых точечных
вихрей — со своими кодами, своей монографией, своей лестницей верификации
и своими протоколами.*

Версия 1.1.0 · Лицензия: LicenseRef-Proprietary-Wild8Highlander-1.0
(см. LICENSE.md в корне репозитория) · Python 3.10+ · numpy

---

## Что это такое

Родительский фреймворк держится на **теореме 3.1** — замкнутой хореографии
трёх вихрей с топологическим интегралом Чаплыгина
$\omega = (2\pi/T)e^{C_{Ch}/\pi}$ — и проверяет классический слой модели
лестницей V1–V4. Этот мини-репозиторий поднимает всю картину на
произвольное $N$ и измеряет, где именно два слоя модели соприкасаются:

- **Слой K** — динамика точечных вихрей Кирхгофа (численная);
- **Слой G** — топологическая замкнутая форма и её калибровочный закон
  (аналитическая).

Научный результат — семиступенчатая лестница **W1–W7** и публикационный
стек, смоделированный один в один с родительским репозиторием:
исследовательская монография ([docs/monograph/](docs/monograph/) — русский
и английский, каждый в Markdown, DOCX и PDF) и **издание монографий по
теоремам** ([docs/monographs/](docs/monographs/) — пять отдельных монографий,
по одной на теорему/лемму, каждая на русском и английском, DOCX и PDF).
Три строгих утверждения:

1. **Теорема B (допустимость).** Замкнутая форма невырождена (радиусы
   строго положительны в любой момент) тогда и только тогда, когда
   $C_{Ch} > \pi\ln 2 = 2.177586090303602\ldots$; на пороге амплитуда
   модуляции равна ровно $\varepsilon = 1$. Зарегистрированное в родителе
   значение $C_{Ch} = 1$ лежит ниже порога — точная разрешимая граница,
   поставленная в очередь роадмапа **T5**.
2. **Лемма C (кинематическое препятствие).** Наведённая радиальная скорость
   правильного $N$-угольника тождественно равна нулю (попарное сокращение),
   поэтому симметрично пульсирующий многоугольник не является орбитой слоя
   K ни при каком $\varepsilon \ne 0$: гипотеза H1 редуцируется к
   классическому жёсткому вращению $\omega_N = \Gamma(N-1)/(4\pi R^2)$.
   Фазосдвинутый вариант H1 проваливает даже регистр формы — линейно,
   с наклоном $\sqrt{3}/2$.
3. **Лемма D (мост усреднённой частоты).** Циклически усреднённая
   кинематическая скорость пульсирующего кольца равна
   $\omega_N (1 - \varepsilon^2)^{-3/2}$ — интегральное тождество,
   сертифицированное до $3 \cdot 10^{-15}$; из него следует кривая
   совместимости **D1**: точные периоды $T_{comp}(N, C_{Ch})$, при которых
   калибровочный частотный закон совпадает с усреднённой кинематикой.

Плюс классические регистры, обобщённые и воспроизведённые численно:
жёсткое вращение измерено до $2.9 \cdot 10^{-12}$ для $N = 2..8$,
интегралы $H, P, Q, I$ сохраняются до $4.2 \cdot 10^{-14}$, а **порог
Хэвелока** (устойчивость при $N \le 7$, неустойчивость при $N \ge 8$)
воспроизведён спектрально с запасом в три порядка
($N = 8$: $\max\operatorname{Re}\lambda = +0.450$).

## Лестница W

| ступень | регистр | статус | протокол |
|---------|---------|:------:|----------|
| W1 | якорь теоремы 3.1 при $N = 3$: разделение, периодичность, пиннед-литералы | PASS | `W1_anchor_default.json` |
| W2 | жёсткое вращение $N$-угольника, $N = 2..8$: формула $\omega_N$ + форма | PASS | `W2_ring_rotation_default.json` |
| W3 | интегралы $H, P, Q, I$ вдоль орбит | PASS | `W3_invariants_default.json` |
| W4 | спектральная устойчивость: порог Хэвелока | PASS | `W4_stability_default.json` |
| W5 | допустимость: $\varepsilon < 1 \iff C_{Ch} > \pi \ln 2$ | PASS | `W5_admissibility_default.json` |
| W6 | кинематическое препятствие (лемма C + регистр формы H1) | PASS | `W6_obstruction_default.json` |
| W7 | мост усреднённой частоты + таблица $T_{comp}$ (D1) | PASS | `W7_bridge_default.json` |

Ступени W1–W3 обобщают родительские регистры V1–V3; W4–W7 — новый
исследовательский контент. Каждый протокол — детерминированный JSON,
привязанный к запуску; тесты заново выводят независимые от пресета числа.

## Быстрый старт

```bash
# из корня репозитория
cd polyvortex

make ladder   # W1..W7 (пресет default), обновить JSON-протоколы
make quick    # дым за 1.3 с
make figures  # перегенерировать figures/ (PNG 300 dpi + схема SVG)
make test     # pytest-охрана (26 тестов, ~2 с)
make lint     # black --check + ruff + mypy (только мини-репо)
```

Раннер умеет запускать и одну ступень:

```bash
python3 python/polyvortex/runner.py --stage W4 --preset default
```

## Связь с родительским фреймворком

| родительский регистр | здесь | примечание |
|----------------------|-------|------------|
| V1 (регистры теоремы 3.1) | W1 | литералы совпадают бит-в-бит при $N = 3$ |
| V2 (жёсткое вращение Лагранжа) | W2 | обобщено до $\omega_N$, $N = 2..8$ |
| V3/V4 (сохранение интегралов) | W3 | N-универсально |
| роадмап **T1** (кольцо N-угольника) | теорема A + W2 | числовая тень тождества корней единства |
| роадмап **T3** (спектральная устойчивость) | W4 | прототип спектральной задачи |
| роадмап **T5** (область допустимости) | теорема B + W5 | точная граница $\pi\ln 2$ |
| очередь теорем §18 | монография §8 | очередь формализации TB1→TW5 |

Мини-репозиторий никогда не импортирует родителя в рантайме; родитель
импортируется только тестами как эталонный оракул — та же дисциплина
пиннинга, что и у языковых портов родителя.

## Заметки о честности

- Гипотеза H1 **не** является решением Кирхгофа при $\varepsilon \ne 0$
  (лемма C); калибровочный частотный закон и кинематика согласуются только
  вдоль кривой D1. Монография разделяет слои принципиально.
- Зарегистрированные родителем значения $(C_{Ch}, T) = (1, 2\pi)$ лежат
  ниже порога допустимости; структурные регистры этого не видят, полярные —
  видят. См. разделы 5 и 10 монографии.
- Устойчивость спектральная (линейная), не нелинейная; за пределами
  линеаризованной классификации ничего не утверждается.

## Роадмап мини-репозитория

1. **P1 — формализовать TB1** (теорему B) в Coq и Lean 4: самое дешёвое
   разрешимое утверждение; числовой протокол — оракул.
2. **P2 — TB2/TW4** (лемма C + теорема A): тождество корней единства в
   Mathlib; попарное сокращение хорд в Coq.
3. **P3 — TB3** (лемма D): дифференцированный интеграл Пуассона либо
   интервальный сертификат на $[-0.9, 0.9]$.
4. **P4 — расширение**: неравные циркуляции $\{\Gamma_k\}$ (когда
   правильное кольцо остаётся относительным равновесием?), кольца колец и
   карта устойчивости по сетке отношений $\Gamma$ (кормит родительский R4).
