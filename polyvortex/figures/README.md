# POLYVORTEX — the figure gallery

The publication figures of the N-vortex extension bench at **300 dpi**,
generated by the protocol-bound factory
[`python/polyvortex/figures.py`](../python/polyvortex/figures.py)
(`make figures` from the mini-repo root). Every plotted register is read
from the committed protocols in
[`results/protocols/`](../results/protocols/); the trajectory panels are
recomputed from the model modules by design — pictures *of* the program,
not registers — while every number quoted in a title or a legend comes
from a protocol.

## Regeneration

```bash
make figures     # from the mini-repo root
```

Requirements: `numpy`, `matplotlib`. The committed protocols must exist
(`make ladder` first) — the factory exits with a pointed error message
otherwise.

## Palette and style

The TRIVORTEX brand palette: navy `#0A1A3A`, steel `#2E5FA3`, sky
`#7FA6D9`, crimson `#B03A2E`, green `#1E8449`, soft grid `#D5DCE8`.
Shared axis styling (`_style_axis`): navy spines, ticks in, grid behind
— the same visual family as the parent repository and the sibling
mini-research [`cycloring`](../../cycloring/figures/).
