## 1. TL;DR — что живёт в этой папке

N-вихревого расширения: единый самодостаточный артефакт `Polyvortex.lean`,
поднимающий аналитический хребет родительской монографии с `N = 3` на

## 3. Почему Lean 4 + Mathlib

Родительская монография сертифицирует числовые лестницы конечной
плавающе-точечной верификацией. Это сертифицирует *экземпляры*. Lean
сертифицирует *предложение*: «для всякого `N ≥ 2`, всякого радиуса `R > 0`,
всякой циркуляции `Γ`, всякого примитивного корня `ζ` и всего времени `t`
кольцо `z_k(t) = R·ζ^k·e^{iω_N t}` решает поле Кирхгофа» — с кванторами
`∀`, которые лестница никогда не исчерпает. Три вещи становятся
машинно-проверенными фактами вместо численно-подкреплённых убеждений:

1. **Принуждение.** `ringOrbit_sol` — бикондиционал: равномерно вращающееся
   кольцо — решение *если и только если* `ω = ω_N`. Числа подтверждают
   скорость до 15 знака; бикондиционал закрывает 16-й и все дальнейшие.
2. **Препятствие.** Лемма C — *отрицательный* результат: никакое пульсирующее
   кольцо не едет на поле. Лестница может лишь не найти его; доказательство
   Lean изымает весь класс анзацев.
3. **Замкнутые интегралы.** Интеграл Пуассона и его квадрат (ядро Леммы D) —
   точные тождества при `|ε| < 1`, доказанные явной антипроизводной —
   ошибки квадратуры, которую надо было бы ограничивать, просто нет.

Mathlib даёт аналитическую инфраструктуру (интервальные интегралы, цепочки
`HasDerivAt`, теорию `Real.cos`/`arctan`, переиндексацию `Finset.sum`), поэтому
артефакт несёт только вихревую математику — ~1 400 строк против 6 589 строк
родительского файла: N-обобщение живёт на одном параметрическом хребте вместо
тройного дублирования индексов.

## 4. Что здесь доказано — пять сертифицированных слоёв

### §1 Теорема A — правильное N-угольное кольцо (принуждено)

Для `N ≥ 2`, `R ≠ 0`, примитивного корня `ζ` и `ω_N := Γ(N−1)/(4πR²)`:

- `ring_velocity` — `kirchhoff γ (ringPos R ζ) N k = i·ω_N·(R ζ^k)` в каждой
  вершине. Доказательство переиндексирует сумму наведённых скоростей по
  циклическому расстоянию `d = (j+N−k) mod N` и схлопывает её тождеством
  `sum_roots_of_unity: Σ_{m∈range(N−1)} 1/(1−ζ^{m+1}) = (N−1)/2` —
  инволюция `m ↦ N−m` (неподвижная точка `m = N/2` даёт `1/2` тем же
  тождеством поля — без разбиения по чётности).
- `ringOrbit_sol` — **теорема принуждения**: кольцо — решение ⟺ `ω = ω_N`.
  Полигонный аналог родительской `lag_omega_unique`.
- `kirchhoff_smul` — вращательная эквивариантность: умножение на единичный
  комплексный множитель переводит решения в решения (так статичное кольцо
  становится орбитой).
- `rootExp_prim` — канонический корень `exp(2πi/N)` примитивен (через
  `Real.cos_eq_one_iff`, без циклотомической машинерии).
- `ringOmega_three_eq_lagrange` — при `N = 3`, `R = a/√3` скорость в точности
  лагранжева `3Γ/(2πa²)` родителя: артефакты сцеплены на общем объекте.

### §2 Теорема B — порог допустимости

Для `C > 0`, `ω ≠ 0` и глубины Чаплыгина `ε = 1/(exp(C/π) − 1)`:

- `rClosed_pos_iff` — все радиусы пульсирующего анзаца строго положительны
  ** iff** `π·ln 2 < C`. Прямая сторона считает анзац в `t = π/ω`, где
  `cos = −1`, и считывает `1 − ε ≤ 0`.
- `rClosed_touches_zero_at_threshold` — при `C = π ln 2` пульсация касается
  нуля ровно раз за период и остаётся неотрицательной (гейт H1 родителя,
  поднятый на кольцо).

### §3 Лемма C — препятствие пульсации

- `ring_radial_zero` — на точном кольце радиальная скорость тождественно
  нулевая (кольцо — решение формы, а не дыхания).
- `lemmaC_pulsation` + `lemmaC_radius_constant` — если равномерно вращающаяся
  пульсирующая конфигурация удовлетворяла ОДУ Кирхгофа, её радиус был бы
  стационарен (`is_const_of_deriv_eq_zero`); отсюда
- `lemmaC_H1_reduction` — любая нетривиальная пульсация Чаплыгина (`ε ≠ 0`)
  не есть решение Кирхгофа. Препятствие, которое родитель аргументировал
  численно, здесь — теорема обо всём классе пульсирующих колец.

### §4 Лемма D — усреднённая скорость и интеграл Пуассона

- `lemmaD_omega_independent` — циклическое среднее факторизуется как
  `ω_N · (1/2π)·∫₀^{2π}(1+ε·cos φ)^{−2} dφ`: частота пульсации выпадает
  подстановкой `φ = ωt` (`integral_comp_mul_left`).
- `poisson_integral` — `∫₀^{2π} dφ/(1+ε·cos φ) = 2π/√(1−ε²)` при `|ε| < 1`,
  в замкнутой форме: полуугловая антипроизводная
  `poissonG ε φ = (2/√(1−ε²))·arctan(√((1−ε)/(1+ε))·tan(φ/2))`, разрез в `π/2`,
  где всё гладко, перенос `φ ↦ π − φ` и финал `arctan k + arctan(k⁻¹) = π/2`.
  Несобственных интегралов нет нигде.
- `poisson_sq` — квадратичный компаньон через поточечное тождество
  `1/(1+ε·cos φ)² = (1/(1−ε²))·(1/(1+ε·cos φ) − ε·g′(φ))`, `g = sin φ/(1+ε·cos φ)`;
  телескопический член интегрируется в `g(2π) − g(0) = 0`.
- `lemmaD_bridge` — усреднённая скорость равна `ω_N/((1−ε²)·√(1−ε²))`:
  дыхание *замедляет* эффективную скорость кольца ровно на множитель
  `1/(1−ε²)^{3/2}`.

### §5 Теорема E — statement-слой W4 (записан, не заявлен)

`corotatingField`, `ring_fixed_point`, `ring_corotating_constant` — со-вращающееся
поле и его вырождение вдоль орбиты — доказаны. Полная классификация

```lean
def havelockClassification : Prop :=
  ∀ (N : ℕ) (γ R : ℝ), 2 ≤ N → R ≠ 0 →
    spectrallyStable γ (ringOmega γ R N) R N (rootExp N) ↔ N ≤ 7
```

— **записана как точный критерий приёмки вехи TW5** и здесь НЕ доказана;
родительская монография сертифицирует её численно. Этот файл добавляет честную
границу: утверждение запечатано, сертификаты его непустоты (неподвижная точка,
вырождение орбиты, принуждение) — теоремы.

## 6. Глубокое погружение — секция за секцией (§0–§5)

**§0 (12 деклараций, private).** Всё переиспользуемое доказано от
`Finset.sum_range_succ`: `sum_rot` (перевод `m ↦ (m+c) mod N` инвариантен
для сумм — индукция по `c`), `sum_range_reflect_aux` (инволюция
`m ↦ (n−1)−m` — индукция по `n` со сдвиг-леммой, применённой к `f ∘ (+1)`),
`sum_erase_zero` (стёртая точка даёт нулевой вклад). ℂ-хелперы (`conj_mul'`,
`conj_pow'`, `normSq_mul'`, `normSq_ne_zero'`) выведены из
`Complex.normSq_eq_conj_mul_self`, чтобы артефакт не зависел от того, какие
simp-леммы `normSq` может переименовать рефакторинг Mathlib.

**§1 (28 деклараций).** Модульная бухгалтерия (`mod_add_zero_eq`,
`mod_add_eq_self`, `mul_pred_mod`) доказана на отменах `Nat.ModEq` — без
ставки на omega-рассуждения с переменным модулем. Потерчленная лемма
`ring_term` сводит один вклад в наведённую скорость к
`iζ^k/(R(1−ζ^{N−d}))`: сопряжённое `conj(ζ^d) = ζ^{d(N−1)}` и приведение
`d(N−1) ≡ N−d (mod N)` делают всю работу. Тождество и `ring_velocity`
собирают полную сумму. Прямая сторона теоремы принуждения идёт по цепочке
эквивариантности `kirchhoff(e^{iωt}·ring) = e^{iωt}·kirchhoff(ring) =
iω_N·e^{iωt}·ring`; обратная сокращает ненулевой множитель орбиты против
`ringOrbit_deriv`.

**§2 (9).** Чистый вещественный анализ на `cos ∈ [−1,1]`: пороговый
бикондиционал читает анзац в одном удачно выбранном времени; сертификат
касания комбинирует `eps_at_threshold` с `cos π = −1`.

**§3 (6).** Доказательство-препятствие умножает уравнение ОДУ на
`conj(e^{iθ(t)})` (единичный множитель), берёт вещественные части — и все
угловые члены исчезают, оставляя `r' = 0`. Редукция затем вычисляет анзац в
`t = 0` и `t = π/ω` и находит `1 + ε ≠ 1 − ε` при `ε ≠ 0`.

**§4 (17).** Техническое сердце. Транспорт-лемма `htrans` двигает
`∫_{π/2}^{π} f(ε)` на `∫₀^{π/2} f(−ε)` через `x ↦ x − π` и затем `x ↦ −x`
(`integral_comp_sub_right`, затем `integral_comp_mul_left` с `c = −1`);
половины складываются через `G(ε) + G(−ε)`; `G(±ε, 0) = 0`, ибо `tan 0 = 0`;
граничная пара схлопывается леммой `arctan_add_arctan_inv`. Квадратичный
компаньон едет на `g = sin/(1+ε·cos)`, производная которой интегрируется
в ноль по замкнутому циклу — консервативный член в чистом виде.

**§5 (6).** Нарочито минимально: со-вращающийся слой и два сертификата
вырождения доказаны; классификация — запечатанный `Prop`. Асимметрия —
смысл: TW5 наследует критерий, а не обещание.

## 7. Футпринт аксиом — ничего, кроме классических оснований

`Polyvortex.lean` заканчивается 26 директивами `#print axioms`, покрывающими
каждую публичную теорему §1–§5. Гейт `tools/axioms_gate.py` компилирует файл
и требует, чтобы каждый футпринт был в точности

```
propext · Classical.choice · Quot.sound
```

— классической сигнатурой Mathlib, — и дополнительно отвергает `sorry`,
объявления `axiom`, `native_decide`, `unsafe` и любой warning компилятора.
В файле нет ни `sorry`, ни `axiom` (грепается и принуждается гейтом, как
только встанет тулчейн-прогон).

## 15. FAQ

**Здесь каждое доказательство машинно-проверено?** Ещё нет — см. рамку в §1.
Утверждения запечатаны, гейты, которые принудят машинную проверку, стоят и
зелёные на некомпиляторной стороне. Первая `lake build` — ближайшая веха.

**Почему `havelockClassification` — `def`, а не `theorem`?** Потому что оно не
доказано. Записать недоказанный критерий теоремой можно только через
`sorry` — запрещено. Запечатанное `Prop`-определение с явным докстрингом —
честная форма: критерий точен, назван и готов к TW5.

**Почему всюду деления на `Real.pi` в `ω_N`?** Это математика: парный
множитель Кирхгофа `Γ/(2π)` и хордовая сумма `(N−1)/2` его производят.
Нормировочных трюков ради красоты утверждения не применялось.

**Почему `sum_roots_of_unity` не разбирает чётность `N`?** Инволюция
`m ↦ N−m` парит индекс `m` с `N−2−m`; в неподвижной точке парная лемма
`1/(1−x) + 1/(1−x⁻¹) = 1` вырождается в `1/(1−x) = 1/2` при
`x = −1 = ζ^{N/2}` — то же тождество поля это покрывает. Один случай,
все чётности.

**Что в аудит-файле?** Байт-в-байт снимок v1.0 с аудит-шапкой. На следующем
релизе `Polyvortex.lean` двигается вперёд, а `Polyvortex_audit.lean`
замораживает уходящий слой — конвенция аудита родителя, применённая с
рождения.

## 16. Устранение неполадок

- **`lake: command not found`** — поставьте elan; файл toolchain сам выберет v4.6.0.
- **`axioms_gate` падает на свежем клоне** — сначала `lake exe cache get`;
  холодная сборка Mathlib идёт часами и не нужна никогда.
- **`seal_check --check` красный после правки теоремы** — вы изменили
  запечатанное утверждение. Посмотрите diff; если правка задумана —
  `seal_check --update` (видимое действие).
- **`lint_conventions` отвергает имя** — новые декларации обязаны быть
  snake_case (теоремы) / lowerCamelCase (defs); grandfather-список пуст и
  пустым остаётся.
- **Мост сообщает о расхождении** — `verified_params.json` разошёлся с
  печатями; перезапустите `export_verified_params.py`, поняв, что изменилось
  в утверждениях.

## 18. Как внести вклад

Печати делают вклад ревьюемым: поменяли утверждение — гейт 3 красный; уронили
докстринг — гейт 4 красный; подстроили константу — гейт 5 красный. Каждый
красный гейт чинится *явным* действием обновления (`--update`,
`--update-baseline`, реэкспорт моста), которое само называет себя в diff.
Новые декларации — snake_case и документированные; новые теоремы вступают в
аксиомный футпринт.
