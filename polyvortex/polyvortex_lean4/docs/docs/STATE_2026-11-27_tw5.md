### Определение corotLin (добавить в HavelockSetup)
```lean
noncomputable def corotLin (γ R : ℝ) (N : ℕ) (ζ : ℂ) (u : ℕ → ℂ) (k : ℕ) : ℂ :=
  -Complex.I * ((ringOmega γ R N : ℝ) : ℂ) * u k
    - Complex.I * (((γ / (2 * Real.pi * R ^ 2) : ℝ) : ℂ)) * ζ ^ (2 * k)
      * ∑ d in Finset.Ico 1 N,
        (star (u k) - star (u ((k + N - d) % N))) / (1 - ζ ^ d) ^ 2
```
Нужные леммы: `corotLin_periodic` (сохраняет N-периодичность:
ζ^{2(k+N)} = ζ^{2k}·(ζ^N)²; (k+N+N−d)%N = (k+N−d)%N), `corotLin_add`,
`corotLin_real_smul` (документационные), **ядро TW3**:
`corotLin γ R N ζ (fun k => Complex.I * ringPos R ζ k) k = 0` — вычисление:
star(u k) − star(u((k+N−d)%N)) = −iR·star(ζ^k)·(1−ζ^d) (исп. star_mul,
ζ^{N−d} = star(ζ^d), star_star); сумма = −iR·star(ζ^k)·(N−1)/2
[sum_roots_of_unity + sum_Ico1 + Finset.sum_mul]; итог: Rζ^k·(Ω − c0(N−1)/2) = 0,
где ζ^{2k}·star(ζ^k) = ζ^k через ζ^k·star(ζ^k) = 1
[rw [star_ζ_pow hN0 h1 hunit, mul_comm, zinv_mul hN0 h1]].

### Мастер-лемма проекции (главная лемма чанка 3)
Для N-периодической u, любого n:
```lean
∑ k in range N, corotLin γ R N ζ u k * star (ζ ^ (n * k))
  = -Complex.I * ((ringOmega γ R N : ℝ) : ℂ) * fmode u n
    - Complex.I * ((γ/(2*Real.pi*R^2) : ℝ) : ℂ) * havS N ζ (havSig N n)
      * star (fmode u (havSig N n))
```
Путь: (1) разложить на −iΩ-часть и анти-часть; (2) Finset.sum_comm по k,d;
(3) на 1/(1−ζ^d)² вынести d-слагаемое; (4) внутренняя сумма по k:
обозначить w j := ζ^{2j}·star(ζ^{n·j}) — тогда Σ_k w(k)·conj(u k) − Σ_k w(k)·conj(u((k−d)%N));
вторая сумма = w_d·Σ_j w(j)·conj(u j), где w((j+d)%N) = w(j)·w_d,
w_d := ζ^{2d}·star(ζ^{n·d}) — через star_mul + pow_add + pow_congr_mod;
ПЕРЕСТАНОВКА k ↦ (k+N−d)%N — Finset.sum_nbij' с обратным (j+d)%N (мод-леммы
((k+N−d)%N + d)%N = k при k<N — через Nat.ModEq-цепочки, как key_mod_eq);
(5) Σ_j w(j)·conj(u j) = star(fmode u (havSig N n)) — т.к. ζ^{havSig·j} = ζ^{2j}·star(ζ^{n·j});
(6) 1 − w_d = 1 − ζ^{havSig·d} → сумма = havS N ζ (havSig N n) ✓.

### Вытеснение (I)–(IV) → ℓ²+Ω²−β² = 0
Дано eigenvalueOf(ℓ): u v ≠ (0,0), N-периодичны, Lu = a·u − b·v, Lv = b·u + a·v
(a := ℓ.re, b := ℓ.im), L = corotLin. Мастер-лемма (ℂ-линейность fmode ✓) даёт СИСТЕМУ ∀n:
(a+iΩ)·C_n − b·D_n = −iβ_m·star(C_m)  и  b·C_n + (a+iΩ)·D_n = −iβ_m·star(D_m),
где C_n := fmode u n, D_n := fmode v n, m := havSig N n, β_m := c0·havS m.
Выбрать n₀ < N с (C_{n₀},D_{n₀}) ≠ (0,0) (иначе fmode_inversion ⇒ u=v=0 ✗).
P := C_{n₀}+iD_{n₀}, P' := C_{n₀}−iD_{n₀} ⇒ P ≠ 0 ∨ P' ≠ 0.
Комбинации уравнений (в точке n₀ и n = m = σn₀, β := β_{n₀} = β_m через havS_sym):
(I)  (a+i(Ω+b))·P  = −iβ·conj(Q')   [Q' := C_m − iD_m]
(II) (a+i(Ω+b))·Q  = −iβ·conj(P')   [Q := C_m + iD_m]
(III)(a+i(Ω−b))·P' = −iβ·conj(Q)
(IV) (a+i(Ω−b))·Q' = −iβ·conj(P)
Вывод (все умножения — кольцевые тождества в ℂ):
- P ≠ 0: если a+i(Ω+b) = 0 ⇒ ℓ = −iΩ ⇒ Re ℓ = 0 ✓. Иначе (I) ⇒ β≠0 ∧ Q'≠0;
  (IV)×conj(I): (ℓ²+Ω²−β²)·Q'·conj(P) = 0 ⇒ **ℓ²+Ω²−β² = 0** ✓
  [(a+i(Ω+b))(a−i(Ω−b)) = a²+Ω²−b²+2iab = ℓ²+Ω² ✓].
- P' ≠ 0: симметрично: ℓ = iΩ или (conj ℓ²)+Ω²−β² = 0 ⇒ ℓ²+Ω²−β² = 0 ✓.
Дальше: ℓ² = β²−Ω² ∈ ℝ ⇒ 2·(Re ℓ)·(Im ℓ) = 0 ∧ (Re ℓ)² − (Im ℓ)² = β²−Ω²;
при β² ≤ Ω² (порог) ⇒ Re ℓ = 0 ✓.
