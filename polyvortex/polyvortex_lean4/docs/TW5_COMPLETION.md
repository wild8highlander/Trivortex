```lean
theorem havelockClassification (γ R : ℝ) (hN3 : 3 ≤ N) (hR : R ≠ 0) (hγ : 0 < γ) :
```

Математическое ядро TW5 — **замкнутая форма блок-сумм Хавелока**

```text
S_m = ∑_{d=1}^{N−1} (1 − ζ^{md}) / (1 − ζ^d)²  =  (2−m)(N−m)/2,   1 ≤ m ≤ N−1,
```

доказанная телескопированием через частичные суммы `C_t = ∑ ζ^{td}/(1−ζ^d)`
(`havC_zero`, `havC_one`, `havC_step`, `havC_chain`, `havS_step`,
`havS_closed`), и **порог малых колец**: `|S_m| ≤ (N−1)/2` при `N ≤ 7`
(`havS_real_sq`). Дисперсионное соотношение

```text
ℓ² + Ω² = β·conj β,   β = (γ/2πR²)·S_{n₀},
```

связывает спектральное значение `ℓ = a + i·b` с блок-суммой несущей моды.
При `N ≤ 7` модуль `β` не превосходит `Ω = γ(N−1)/(4πR²)` — вещественная часть
обнуляется (`corotLin_stable7`). При `N ≥ 8` мода-свидетель `n₀ = N−3` даёт
`|S_{n₀}| > (N−1)/2`, и явная растущая мода

```text
λ = √(β² − Ω²) > 0   на паре мод n₀ = N−3, m = havSig n₀ = 5
```

строится руками (`havelock_witness`): u_k = (p + i)·(ζ^{n₀k} + ζ^{5k}),
v ≡ 0 с p = (Ω − β)/λ. В нормировке Γ = 1, R = 1 на пороговом кольце N = 8:

```text
S_5 = −9/2,  β = −9/(4π),  Ω = 7/(4π),  λ = √(β²−Ω²) = √2/π ≈ 0.4502.
```

Эта константа выгружена в мост `verification/polyvortex/data/verified_params.json`
(`havelock_witness_N8`) — мост впервые материализован, 9 сертифицированных констант.
