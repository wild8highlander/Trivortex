the protocol-bound factory [`python/cycloring/figures.py`](../python/cycloring/figures.py)
(`make figures` from the mini-research root). This folder holds the
**English primary edition**; the Russian mirror lives in
[`figures/ru/`](ru/). Both editions are regenerated from the same
committed protocols in [`results/protocols/`](../results/protocols/) —
identical numbers, palettes and layout, two languages.

## The discipline

Every plotted register is **read from a protocol file, never
re-invented**: the trajectory panels are recomputed from the model
modules by design (they are pictures *of* the program, not registers),
but every number quoted in a title or a legend comes from the committed
JSON protocols. A figure and a protocol cannot disagree — both come from
the same run.

## Regeneration

```bash
make figures                          # both language editions
python3 -m cycloring.figures --lang en   # this edition only (PYTHONPATH=python)
```

Requirements: `numpy`, `mpmath`, `matplotlib`. The committed protocols
must exist (`make ladder` first if they are missing) — the factory exits
with a pointed error message otherwise.

## Palette and style

The palette is the TRIVORTEX brand: navy `#0A1A3A`, steel `#2E5FA3`,
sky `#7FA6D9`, crimson `#B03A2E`, green `#1E8449`, soft grid `#D5DCE8`.
Axis styling is shared (`_style_axis`): navy spines, ticks in, grid
behind. The same system renders the parent repository's figures, so the
galleries are visually one family.
