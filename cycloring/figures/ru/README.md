# CYCLORING — галерея графиков (русское зеркальное издание)

Публикационные графики мини-исследования в **300 dpi**, генерируемые
привязанной к протоколам фабрикой
[`python/cycloring/figures.py`](../../python/cycloring/figures.py)
(`make figures` из корня мини-исследования). Эта папка — **русское
зеркало**; английская основная редакция живёт в [`figures/`](../).
Обе редакции перегенерируются из одних и тех же закоммиченных протоколов
в [`results/protocols/`](../../results/protocols/) — одинаковые числа,
палитры и компоновка, два языка.

## Дисциплина

Каждый изображённый регистр **читается из файла протокола, а не
выдумывается заново**: траекторные панели намеренно пересчитываются из
модулей модели (они — картинки *программы*, а не регистры), но каждое
число в заголовке или легенде приходит из закоммиченных JSON-протоколов.
График и протокол не могут разойтись — оба происходят из одного прогона.

## Перегенерация

```bash
make figures                          # обе языковые редакции
python3 -m cycloring.figures --lang ru   # только эта редакция (PYTHONPATH=python)
```

Требования: `numpy`, `mpmath`, `matplotlib`. Закоммиченные протоколы
должны существовать (сначала `make ladder`) — иначе фабрика завершается
с внятной ошибкой.

## Палитра и стиль

Палитра — фирменная TRIVORTEX: navy `#0A1A3A`, steel `#2E5FA3`, sky
`#7FA6D9`, crimson `#B03A2E`, green `#1E8449`, мягкая сетка `#D5DCE8`.
Оформление осей общее (`_style_axis`): navy-рамки, тики внутрь, сетка
под данными. Та же система рендерит графики родительского репозитория,
поэтому галереи — одна визуальная семья.
