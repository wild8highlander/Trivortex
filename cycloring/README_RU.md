# CYCLORING — лаборатория Γ-периодов кольца

*Самодостаточная мини-исследовательская программа: правильное N-вихревое
кольцо как алгебраический объект — корневая система одного двучлена —
с угловыми фазами на циклотомической решётке и радиальной модуляцией,
порождаемой Γ-периодами через конечную цепочку дефектов. Программа несёт
собственные коды, собственную верификационную лестницу, собственные
протоколы, собственные графики и собственные монографии.*

Версия 1.0.0 · Лицензия: LicenseRef-Proprietary-Wild8Highlander-1.0
(см. LICENSE.md в корне репозитория) · Python 3.10+ · numpy, mpmath

## Что это

Программа исходит из замороженного правильного N-угольника одинаковых
точечных вихрей (жёсткое относительное равновесие, вращающееся со
скоростью $\omega_L = \Gamma(N-1)/(4\pi R^2)$) и задаёт один вопрос:
**можно ли всю дыхательную динамику кольца прочитать из конечного набора
периодов уровня?** Собранный здесь ответ — да, через четыре регистра:

1. **Кольцо — корневая система (теорема 1).** Конфигурация
   $z_k(t) = r(t)\,\zeta_N^k e^{i\nu t}$ — это в точности полный набор
   корней уравнения $z^N = \sigma(t)$, где
   $\sigma(t) = r(t)^N e^{iN\nu t}$; суммы степеней удовлетворяют
   $S_m = \sum_k z_k^m = 0$ при $m < N$ и $S_N = N\sigma$, линейный импульс
   тождественно нулевой, а группа Галуа
   $\mathrm{Gal}(\mathbb{Q}(\zeta_N)/\mathbb{Q})$ действует на кольцо
   релябелингом вихрей — решётка характеров $\widehat\mu_N$ и есть
   модовое разложение кольца.
2. **Граница области периодов алгебраична (теорема 2).** Для
   $\Omega_{a,b} = \Gamma(a/N)\Gamma(b/N)/\Gamma((a+b)/N)$ тождество
   отражения даёт $\Omega_{a,N-a} = \pi/\sin(\pi a/N)$ — каждый граничный
   период есть алгебраическое кратное π, а внутренние периоды — подлинные
   Γ-трансцендентности. Синусное произведение
   $\prod_m 2\sin(\pi m/N) = N$ — алгебраический хребет всей конструкции.
3. **Цепочка дефектов — трансдьюсер периодов (теорема 3).** Из тройки
   $(N, B, \lambda_0)$ — уровень, угловой импульс, замороженная частота —
   цепочка $\delta = \pi/N$, $k = \lceil B\lambda_0/\Gamma^2\rceil$,
   $\gamma = \delta^4/k$, $\delta_{eff} = \delta^5/k$,
   $\Delta_{Ch} = \gamma W_N/(N-1)$ порождает модуляционную программу
   $\varepsilon = \Delta/(1+\Delta)$,
   $\nu = \omega_L (1+\Delta)^3/(1+2\Delta)^{3/2} = \omega_L(1-\varepsilon^2)^{-3/2}$,
   $C_N = \ln(1+1/\Delta) = -\ln\varepsilon$. Классический предел
   $\Delta \to 0$ возвращает жёсткое кольцо.
4. **Синхронное дыхание замыкается точно (теорема 4).** Среднее по циклу
   от замороженного закона переноса равно
   $\langle(1+\varepsilon\cos u)^{-2}\rangle = (1-\varepsilon^2)^{-3/2}$ —
   выбор ν в точности равным этому среднему заставляет каждый вихрь ехать
   по замкнутой розетке и возвращает всю конфигурацию через
   $T_c = 2\pi/\nu$. Регистр дихотомии (теорема 5): произведение попарных
   расстояний и дискриминант $N^N\sigma^{N-1}$ алгебраичны, а гамильтониан
   несёт трансцендентную оболочку
   $H(R) = -\frac{\Gamma^2}{2\pi}\left[\frac{N(N-1)}{2}\ln R + \frac{N}{2}\ln N\right]$.

Каждый протокол — детерминированный JSON-файл, привязанный к запуску;
тестовый гард повторно выводит не зависящие от пресета числа. mpmath-регистры
считаются с 50 рабочими знаками (допуск тождеств 1e−30); динамические
регистры используют RK4 (допуск скорости 1e−9, дрейфы инвариантов 1e−12).

## Быстрый старт

```bash
# из корня мини-исследования
cd cycloring

make ladder   # прогнать W1..W7 (пресет default), обновить JSON-протоколы
make quick    # быстрый дым всей лестницы
make figures  # перегенерировать figures/ (300 dpi PNG + схема SVG)
make test     # pytest-гард (37 тестов)
make lint     # black --check + ruff + mypy (скоуп мини-исследования)
```

Раннер умеет адресовать отдельную ступень:

```bash
PYTHONPATH=python python3 python/cycloring/runner.py --stage W5 --preset default
```

## Заметки честности

- Программа дыхания — **кинематическая программа**: у замороженного
  многоугольника нет радиальной скорости в кирхгофовском поле (попарные
  сокращения), поэтому радиальную подпитку обязан поставлять насос;
  угловой же транспорт не предписывается, а следует замороженному закону
  Λ₀/r(t)² — именно поэтому тождество переноса и синхронное замыкание —
  точные утверждения, а не приближения.
- Внутренние периоды Ω(a,b) при a+b ≠ N трактуются как трансцендентные
  константы Γ-типа; никакая алгебраическая редукция для них не
  утверждается и нигде в цепочке не используется — цепочка потребляет
  только нормированные диагональные суммы W_N и алгебраические граничные
  значения.
- Степенной закон Δ_Ch(N) ≈ 1.7·10³·N^{−6.7} — численная аппроксимация на
  N = 3..30, а не асимптотическая теорема; доказана только монотонность γ.
- Все динамические регистры — RK4 с перечисленными допусками; спектральные
  регистры якобиана используются лишь как диагностика, лестница не
  заявляет нелинейных результатов об устойчивости.
